# SOCIAL PHYSICS MVP

An executable social-law / institution-engine prototype.

## Working now
- Natural-language society description → law activation
- Toggleable executable laws
- Anonymous identity enforcement
- Hidden popularity until voting
- Counter-view / steelman gate before publishing
- Optional stance alternation
- Novelty-weighted feed ordering
- Finite-memory mode
- Society A vs relaxed Society B metric simulation
- Persistent state with `localStorage`

## Production boundary
The current fork metrics are interaction-model heuristics for product validation, not behavioral-science claims. Production should add accounts, realtime rooms, auditable policy evaluation, moderation safety layers, experiment assignment, and statistically valid outcome measurement.
