# CAUSAL INTERNET MVP

A personal N-of-1 experiment and causal-evidence graph prototype.

## Working now
- Goal / action / outcome experiment compiler
- Balanced randomized A/B session assignment
- Outcome score and sleep-context logging
- A/B means, difference, standardized signal, and evidence-strength estimate
- Personal cause → outcome → goal graph
- Context split when enough sleep-context observations exist
- Multiple experiments with local persistence

## Important boundary
The MVP displays experimental signals, not scientifically proven causation. The evidence-strength indicator is a product heuristic. Production should use preregistered protocols, robust randomization, missing-data handling, uncertainty intervals, causal inference/statistics libraries, and explicit health/safety restrictions for sensitive experiments.
