# Reality Engine Lab

Three experimental MVPs exploring programmable reality, executable social laws, and personal causal graphs.

- `apps/world-exe` — program real-world triggers and actions.
- `apps/social-physics` — create communities with executable social laws.
- `apps/causal-internet` — run personal N-of-1 experiments and build causal evidence graphs.

Open `index.html` for the launcher or any app folder's `index.html` directly. Everything runs in the browser and persists locally with `localStorage`; no API keys are required for the MVP.

## Run locally

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Product direction

These are functional client-side MVPs intended to validate the interaction model before adding accounts, realtime sync, geospatial infrastructure, and production causal/statistical services.
